# 描き分け（部品）の作り方

元の絵 `src.png`（1024×1024、胸から上、背景は無地の明るい色）から、画像編集 AI に次の絵を描かせます。
**変える所以外は 1 画素も変えない「局所編集」であること**が条件です（絵全体を描き直されると、差分で部品を取り出せません）。

| ファイル | 元にする絵 | 何を描かせるか |
|---|---|---|
| `bald_open.png` | src.png | 髪を全部消して、下の頭・おでこ・耳・首を描く（目は開いたまま） |
| `hair_only.png` | src.png | 髪だけを残し、顔・首・背景を緑 `#00FF00` に。顔で隠れていた髪の内側も描き足す |
| `eye_12.png` … `eye_75.png` | bald_open.png | まぶたを 12%・25%・37%・62%・75% 下ろした目（まばたきの途中） |
| `eye_closed.png` | bald_open.png | 閉じた目 |
| `eye_jito.png` / `eye_smile.png` | bald_open.png | ジト目 / 笑った目（表情） |
| `no_mouth.png` | bald_open.png | 口を消して肌にする（コードで口を描く台） |

目と口は **髪なしの絵（bald_open.png）の上** に描かせます。髪の下に隠れた所まで目が描かれるので、髪が揺れても欠けません。

## Codex CLI で一括

```bash
bash prompts/make_keys.sh gen        # 段階 1（髪なし・髪だけ）→ 段階 2（目・口）
python tools/check_variants.py --gen gen
```

`CODEX=/path/to/codex bash prompts/make_keys.sh gen 2` のようにコマンドと段階を指定できます。
利用上限に当たった絵は `log_*.txt` に "usage limit" と出るので、時間をおいて同じコマンドをもう一度（できた絵は残ります）。

## 他のツール（ChatGPT の画像編集など）で手作業

`_common.txt` の前書き（`{IN}` を元のファイル名に置き換える）＋ 各 `*.txt` の文章を貼り、できた絵を上の名前で `gen/` に保存します。
大きさが変わって返ってきたら（1254px など）、元の大きさに戻してから使います（`check_variants.py` が知らせます）。

## うまくいかないとき

- `check_variants.py` で NG：全体が描き直されている → 前書きの "This must be a LOCAL edit … bit-identical" を強めて作り直す
- 目のコマが「順番が合わない」と除外される：AI は指示した割合どおりに描かないことがある（半目が 37% と同じ高さなど）。`build_layers.py` がまぶたの高さを測って自動で外すので、そのままでよい。段が足りなければ別の割合を描かせて足す
- 髪だけの絵で、髪の形が変わる：AI は「髪だけ残す」で髪を描き直しがち。こちらは奥の髪の色にしか使わないので、形が少し違っても大丈夫
